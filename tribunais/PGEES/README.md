# PGE/ES

Procuradoria-Geral do Estado do Espírito Santo. **58 enunciados administrativos CPGE**, números 01–58, no [catálogo oficial](https://pge.es.gov.br/enunciados).

- [Enunciados administrativos CPGE](en-cpge/)

O órgão é distinto do TJES, TCEES e das Procuradorias de outros entes. A presença no catálogo não comprova vigência atual, força vinculante ou exaustividade. As notas e os textos históricos foram mantidos como publicados. Veja as [fontes e limites](../../COBERTURA.md#pgees--enunciados-administrativos-cpge).
