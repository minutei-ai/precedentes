# CNMP

Conselho Nacional do Ministério Público. **32 registros.**

O CNMP é órgão constitucional próprio. Não se confunde com o Ministério Público Federal, o Ministério Público do Trabalho nem com os Ministérios Públicos dos Estados e do Distrito Federal. O catálogo usado é o da Comissão de Acompanhamento Legislativo e Jurisprudência.
