# MPES · Súmulas do Colégio de Procuradores

Cinco textos do [catálogo oficial](https://mpes.mp.br/sumulas/), em série própria do Colégio de Procuradores de Justiça (COPJ). A página de [composição](https://mpes.mp.br/composicao/) e as notas de Resolução COPJ identificam o contexto institucional; a série é distinta do Conselho Superior.

Os cinco parágrafos jurídicos foram lidos integralmente em duas capturas HTML coincidentes nesse conteúdo. Mantidas as aspas e notas de publicação; ênfases, espaços e quebras foram normalizados. Os PDFs vinculados usam `antigo.mpes.mp.br` (`/Arquivos/Anexos/…pdf`); em 04/11/2026 o host não resolveu DNS (falha de `getaddrinfo`, HTTP efetivo 000 mesmo com TLS relaxado), e a página HTML do catálogo foi recapturada em par HTTP 200 (86.550 bytes, SHA-256 `176440464511a3d0cb87f83984e6264159c96ee05f5907381aa7820c110b0c4a`). Os PDFs não foram baixados nem usados para completar a página. Não houve PDF/OCR nesta série. Não se infere vigência, força vinculante ou completude. Próximo passo: espelho institucional, Wayback com snapshot do PDF, ou republicação no domínio atual.
