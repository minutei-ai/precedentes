# MPSE

Ministério Público do Estado de Sergipe. **18 registros neste lote.**

| Série | Registros |
| --- | ---: |
| [Súmulas de entendimento criminais](sum-criminais/) | 18 |

Órgão próprio, distinto do TJSE, do TCESE e dos Ministérios Públicos de outros estados. Os textos desta série são atribuídos às Procuradorias de Justiça com Atribuições Criminais, sem confusão com CSMP, CPJ ou Procuradorias Cíveis. O quadro de assentos do CSMP está em lote separado ainda não integrado à base deste branch. Não se infere vigência, vinculação ou completude.
