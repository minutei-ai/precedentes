# FONAJEF

Fórum Nacional dos Juizados Especiais Federais, promovido pela Associação dos Juízes Federais do Brasil (AJUFE). **226 enunciados da listagem consultada.** Órgão/série próprio, distinto do FONAJE, da TNU, do CNJ e dos TRFs. A cobertura permanece parcial.
