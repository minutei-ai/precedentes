# CNPG

Conselho Nacional de Procuradores-Gerais dos Ministérios Públicos dos Estados e da União. **62 registros neste órgão.**

| Espécie | Registros |
| --- | ---: |
| [GNCCRIM — enunciados 41–44](en-gnccrim/) | 4 |
| [COPEVID/GNDH — enunciados reproduzidos pelo MPPR](en-copevid/) | 58 |

O CNPG congrega os Procuradores-Gerais dos Ministérios Públicos dos Estados e da União. As séries GNCCRIM e COPEVID/GNDH são identidades distintas. O MPPR aparece apenas como hospedeiro das reproduções consultadas. Não se declara vigência atual nem completude histórica.
